# System Workflow

```text
        Farmer
           ↓
 Regional-Language
    Voice Input
           ↓
   Speech Recognition
           ↓
 Information Processing
           ↓
 Important Details
     Extraction
           ↓
 Structured Farm Record
           ↓
     Digital Diary
           ↓
  Reminder Generation
```

## Main Components

1. **Voice Interface** — accepts spoken input.
2. **Speech Recognition** — processes spoken language.
3. **Language Processing** — handles regional-language input.
4. **Information Extraction** — identifies important farming details.
5. **Digital Farm Diary** — stores structured records.
6. **Reminder Module** — generates useful reminders.
